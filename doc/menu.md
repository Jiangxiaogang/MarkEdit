# Markdown 编辑器菜单功能设计文档

## 1. 菜单栏总体结构

```
┌─────────────────────────────────────────────────────────────────┐
│  文件 (F)  编辑 (E)  视图 (V)  格式 (O)  工具 (T)  帮助 (H)        │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 详细菜单设计

### 2.1 文件 (File) 菜单

**快捷键**: `Alt+F`

| 菜单项 | 快捷键 | 图标 | 功能描述 | 状态 |
|--------|--------|------|----------|------|
| 新建 | `Ctrl+N` | 📄 | 创建新的空白 Markdown 文档 | 始终可用 |
| 打开... | `Ctrl+O` | 📂 | 打开本地 Markdown 文件 | 始终可用 |
| 打开最近的文件 | - | 🕒 | 子菜单，显示最近打开的 5 个文件 | 动态启用 |
| 保存 | `Ctrl+S` | 💾 | 保存当前文档 | 有修改时启用 |
| 另存为... | `Ctrl+Shift+S` | 💾➡️ | 将文档保存为新文件 | 始终可用 |
| 导出为 HTML | `Ctrl+E` | 🌐 | 导出当前文档为 HTML 文件 | 始终可用 |
| 导出为 PDF | `Ctrl+P` | 📄 | 导出当前文档为 PDF 文件 | 始终可用 |
| ────── | - | - | 分隔线 | - |
| 退出 | `Alt+F4` | 🚪 | 关闭应用程序 | 始终可用 |

**实现细节**:
- "最近的文件"列表保存在配置文件中，最多保留 10 条记录
- 导出 PDF 功能需要 Qt PrintSupport 模块
- 文件修改检测通过 `QPlainTextEdit::document()->isModified()` 实现

### 2.4 格式 (Format) 菜单

**快捷键**: `Alt+O`

| 菜单项 | 快捷键 | 图标 | 功能描述 | 状态 |
|--------|--------|------|----------|------|
| 粗体 | `Ctrl+B` | **B** | 切换选中文本为粗体 (**text**) | 有选中内容时启用 |
| 斜体 | `Ctrl+I` | *I* | 切换选中文本为斜体 (*text*) | 有选中内容时启用 |
| 下划线 | `Ctrl+U` | <u>U</u> | 切换选中文本为下划线 | 有选中内容时启用 |
| 删除线 | `Ctrl+T` | ~~S~~ | 切换选中文本为删除线 (~~text~~) | 有选中内容时启用 |
| ────── | - | - | 分隔线 | - |
| 标题 1 | `Ctrl+1` | H1 | 设置为一级标题 (#) | 始终可用 |
| 标题 2 | `Ctrl+2` | H2 | 设置为二级标题 (##) | 始终可用 |
| 标题 3 | `Ctrl+3` | H3 | 设置为三级标题 (###) | 始终可用 |
| ────── | - | - | 分隔线 | - |
| 无序列表 | `Ctrl+L` | • | 将选中行转换为无序列表 (- item) | 始终可用 |
| 有序列表 | `Ctrl+Shift+L` | 1. | 将选中行转换为有序列表 (1. item) | 始终可用 |
| 引用块 | `Ctrl+Q` | ❝ | 将选中行转换为引用块 (> text) | 始终可用 |
| 代码块 | `Ctrl+K` | ``` | 将选中行转换为代码块 | 始终可用 |
| 行内代码 | `Ctrl+'` | `code` | 切换选中文本为行内代码 (`text`) | 有选中内容时启用 |
| ────── | - | - | 分隔线 | - |
| 插入链接 | `Ctrl+Link` | 🔗 | 在光标处插入 Markdown 链接语法 | 始终可用 |
| 插入图片 | `Ctrl+Img` | 🖼️ | 在光标处插入 Markdown 图片语法 | 始终可用 |
| 插入水平线 | - | ― | 插入水平分割线 | 始终可用 |

**实现细节**:
- 格式操作通过正则表达式识别和添加/移除 Markdown 标记
- 支持批量处理多行选中内容
- 智能检测当前格式状态进行切换

## 4. 总结

本菜单设计方案经过精简优化，包含以下特点：

1. **6 个主菜单**: 文件、编辑、视图、格式、工具、帮助
2. **精简的编辑菜单**: 移除了缩进功能和所有插入功能，保留核心编辑操作
3. **精简的视图菜单**: 移除了字体调整功能和工具栏选项，保留核心视图控制
4. **删除预览菜单**: CSS 相关功能移至工具菜单
5. **精简的工具菜单**: 移除了阅读时间估算、语法参考和调试信息
6. **精简的帮助菜单**: 常见问题已删除，关于移动到第一项
7. **精简的预览区右键菜单**: 移除了放大缩小功能

此设计可作为后续 UI 实现的详细规格说明。
